# 理理工作台

一款面向福建教师招聘考试的移动端学习应用，包含英语口语打卡和教师考编（教综 + 中学英语学科）两大模块。

## 功能模块

### 🗣️ 英语口语
- **每日打卡**：可视化日历，记录连续打卡天数
- **情景对话**：15个日常交流场景（餐厅、机场、购物、问路、酒店、医院、社交、面试等），含对话示范、核心句型、核心词汇
- **AI 对话练习**：选择场景或自由对话，与AI进行英语口语交互练习

### 📚 教师考编
- **福建地区专用**：基于福建省中小学教师招聘考试大纲整理
- **教育综合知识**：教育学、心理学、师德法规、时事政治知识点梳理 + 60道练习题
- **中学英语学科**：语法、词汇、阅读、翻译、英美文学、语言学、课程标准与教学论 + 65道练习题
- **章节练习**：按模块筛选刷题，即时判分，查看解析
- **模拟测试**：随机抽题，计时模拟，自动评分，记录错题
- **错题本**：自动汇总练习和模拟中的错题，支持清空复习

## 使用方式

### 方式一：直接打开
在浏览器中打开 `index.html` 文件即可使用。推荐使用 Safari、Chrome、Edge 等现代浏览器。

### 方式二：本地服务器（推荐）
```bash
cd lili-workbench
python3 -m http.server 8080
```
然后在浏览器访问：`http://localhost:8080`

### 方式三：部署到静态托管
将 `lili-workbench` 目录下的所有文件上传到 GitHub Pages、Vercel、Netlify、腾讯云静态网站等托管平台。

## 数据来源

- 福建省中小学教师公开招聘考试（笔试）教育综合知识考试大纲（2025年）
- 福建省中小学教师公开招聘考试（笔试）中学英语学科考试大纲（2025年）
- 日常英语口语实用表达资料

## 注意事项

- 学习数据（打卡记录、答题记录、错题本）保存在浏览器本地存储（localStorage）中
- 清除浏览器数据会导致学习记录丢失，建议定期备份
- 题目和知识点根据公开考纲整理，仅供参考，实际备考请以官方最新大纲为准
